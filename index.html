📚 Cấu trúc định dạng tệp FCQ2

Định dạng tệp FCQ2 (FileCryptoQt v2)
├── Magic: "FCQ2" (4 bytes)
├── Mã thuật toán: 1=AES-CBC+HMAC, 2=AES-GCM, 3=ChaCha20-Poly1305 (1 byte)
├── Salt dẫn xuất: ngẫu nhiên 16 bytes (PBKDF2-HMAC-SHA256 200.000 vòng)
├── Độ dài IV/Nonce: 12 bytes (GCM/ChaCha) hoặc 16 bytes (CBC) (1 byte)
├── IV/Nonce ngẫu nhiên (12 hoặc 16 bytes)
├── Độ dài tên tệp gốc: Big-Endian uint16 (2 bytes)
├── Tên tệp gốc: UTF-8 encoded string
├── Độ dài loại MIME gốc: Big-Endian uint16 (2 bytes)
├── Loại MIME gốc: UTF-8 encoded string
├── Toàn bộ bản mã (Ciphertext)
└── Thẻ xác thực: 16 bytes AEAD Tag (AES-GCM / ChaCha20) hoặc 32 bytes HMAC-SHA256 (CBC)
